# 💩 똥피하기

아이들이 만든 캐릭터로 즐기는 2D 똥피하기 게임입니다.

## 게임 규칙

- 시작할 때 **소녀 캐릭터**와 **까치 캐릭터** 중 하나를 선택합니다.
- 캐릭터를 좌우로 움직여 떨어지는 똥을 피하세요.
  - PC: `←` `→` 방향키
  - 휴대폰: 화면을 터치하거나 드래그
- 똥을 하나 피할 때마다 **점수 +1** (큰 똥은 **+5**)
- **30초마다 레벨업** — 똥이 더 많이, 더 빠르게 떨어집니다.
- **5레벨마다** 일반 똥의 **3배 크기인 큰 똥**이 랜덤한 타이밍에 한 번 떨어집니다.
- 목숨은 **3개**로 시작하고, 똥에 맞으면 하나씩 줄어듭니다.
  (맞은 직후에는 잠시 무적이 되며 캐릭터가 깜빡입니다)
- **5레벨을 깰 때마다 목숨이 1개 늘어납니다. 단 최대 3개까지만.**
  (이미 3개면 그대로 유지됩니다)
- 목숨 3개를 모두 잃으면 게임이 끝나고, 그때의 점수가 **랭킹에 누적**되어 역대 등수가 표시됩니다.

## 실행 방법

### 1. 이 PC에서 바로 하기

`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행됩니다.

### 2. 휴대폰에서 하기 (같은 Wi-Fi)

가장 간단한 방법입니다. **휴대폰과 PC가 같은 Wi-Fi에 연결**되어 있어야 합니다.

1. `게임서버-시작.bat` 파일을 더블클릭합니다.
2. 검은 창에 표시되는 주소를 확인합니다. (예: `http://192.168.45.143:8000`)
3. 휴대폰 브라우저 주소창에 그 주소를 입력합니다.
4. 게임이 실행됩니다! 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
   - iPhone(Safari): 공유 버튼 → "홈 화면에 추가"
   - Android(Chrome): 메뉴(⋮) → "홈 화면에 추가"

> 게임을 하는 동안 검은 창은 켜 둔 채로 두세요. 창을 닫으면 서버가 꺼집니다.

**주소가 안 열린다면?**
- 휴대폰과 PC가 같은 Wi-Fi인지 확인하세요. (휴대폰 데이터가 켜져 있으면 꺼보세요)
- Windows 방화벽 팝업이 뜨면 **"액세스 허용"**을 눌러주세요.

### 3. 인터넷에 올려서 어디서나 하기

Wi-Fi가 달라도, 다른 사람에게 링크를 보내서도 할 수 있습니다.
이 게임은 서버가 필요 없는 정적 웹페이지라 무료 호스팅에 바로 올라갑니다.

가장 쉬운 방법 — **Netlify Drop**:
1. https://app.netlify.com/drop 접속
2. `juchae-game-app` 폴더를 통째로 브라우저에 끌어다 놓기
3. 몇 초 뒤 나오는 주소(예: `https://xxx.netlify.app`)를 휴대폰에서 열면 끝

다른 방법으로 GitHub Pages, Vercel, Cloudflare Pages도 동일하게 사용할 수 있습니다.

## 파일 구성

```
juchae-game-app/
├── index.html          게임 화면 구조
├── style.css           화면 디자인
├── game.js             게임 로직
├── 게임서버-시작.bat     휴대폰 접속용 서버 실행
└── assets/
    ├── character_girl.png     플레이어 - 소녀 캐릭터
    ├── character_magpie.png   플레이어 - 까치 캐릭터
    ├── poop.png               일반 똥
    └── poop_big.png           큰 똥 (5레벨마다 등장)
```

## 캐릭터 추가하기

1. 캐릭터 그림을 **배경이 지워진 투명 PNG**로 만들어 `assets/` 폴더에 넣습니다.
   (배경 제거가 필요하면 **초록색 단색 배경**으로 그린 그림을 주는 것이 가장 깔끔합니다)
2. `game.js` 위쪽의 `CHARACTERS` 목록에 한 줄 추가합니다.

```js
const CHARACTERS = [
  { id: "girl",   name: "소녀 캐릭터", src: "assets/character_girl.png" },
  { id: "magpie", name: "까치 캐릭터", src: "assets/character_magpie.png" },
  { id: "new",    name: "새 캐릭터",   src: "assets/character_new.png" },  // 추가
];
```

선택 화면에 자동으로 나타납니다.
