# 🎮 쭈채 게임 모음

아이들이 만든 캐릭터로 즐기는 미니게임 모음집입니다. 첫 화면(허브)에서 게임을 고른 뒤 시작합니다.

## 🎮 바로 플레이

**https://leternall.github.io/ddong-game/**

휴대폰·태블릿·PC 어디서나 위 주소를 열면 허브 화면이 뜹니다. 설치할 것 없습니다.
(검색엔진에는 노출되지 않도록 설정되어 있어, 주소를 아는 사람만 들어올 수 있습니다)

← → 방향키(또는 화면을 좌우로 밀기)로 게임을 고르고 "시작하기"를 누르면 해당 게임이 시작됩니다.

허브 화면 오른쪽 위 🏆 아이콘을 누르면 게임별 랭킹을 볼 수 있습니다(허브와 동일하게 좌우로 넘기며 게임을 고르는 방식). 왼쪽 위 "← 허브로"로 돌아옵니다.

## 0001. 💩 똥피하기

- 시작할 때 **소녀 캐릭터**와 **까치 캐릭터**(01·02번) 중 하나를 선택합니다.
  (03~08번 캐릭터는 0003 기억력 게임의 카드 그림으로 쓰이고 있어 이 게임의 선택 화면에는 나오지 않습니다)
- 캐릭터를 좌우로 움직여 떨어지는 똥을 피하세요.
  - PC: `←` `→` 방향키
  - 휴대폰: 가고 싶은 곳을 **톡 누르면** 그 자리로 이동합니다. 손가락으로 **끌어도** 됩니다.
- 똥을 하나 피할 때마다 **점수 +1** (큰 똥은 **+5**)
- **30초마다 레벨업** — 똥이 더 많이, 더 빠르게 떨어집니다.
- **5레벨마다** 일반 똥의 **3배 크기인 큰 똥**이 랜덤한 타이밍에 한 번 떨어집니다.
- 목숨은 **3개**로 시작하고, 똥에 맞으면 하나씩 줄어듭니다.
  (맞은 직후에는 잠시 무적이 되며 캐릭터가 깜빡입니다)
- **5레벨을 깰 때마다 목숨이 1개 늘어납니다. 단 최대 3개까지만.**
  (이미 3개면 그대로 유지됩니다)
- 목숨 3개를 모두 잃으면 게임이 끝나고, 그때의 점수가 **랭킹에 누적**되어 역대 등수가 표시됩니다.

## 0002. 🏃 쭈채Run

- 시작할 때 **보라 캐릭터**와 **솜사탕 곰** 중 하나를 선택합니다(똥피하기 03·05번 캐릭터).
- 화면이 세로로 계속 흘러 내려오며, 캐릭터는 **왼쪽·가운데·오른쪽 세 줄** 중 한 줄에 서 있습니다.
- 하단 버튼 3개(**◀ / 점프 / ▶**)로 조작합니다: ◀ ▶로 옆줄 이동, 점프로 구덩이를 뛰어넘습니다.
  - 구덩이는 점프로만 피할 수 있고, 나무·바위는 옆줄로 옮겨야 피할 수 있습니다(점프로는 못 피함).
  - 고기를 지나가면 자동으로 먹고 **+10점**.
- **1m 갈 때마다 +5점**. **100m마다 레벨업**하며 속도가 빨라지고 장애물도 늘어납니다(끝없이 이어집니다). 레벨 1은 여유 있게 시작합니다.
- 목숨은 **3개**로 시작하고, 장애물에 걸리면 하나씩 줄어듭니다(맞은 직후 잠시 무적 — 똥피하기와 동일).
- **고기 50개를 먹을 때마다 목숨이 1개 늘어납니다. 단 최대 3개까지만.**
- 목숨을 모두 잃으면 게임이 끝나고, 그때의 점수가 **랭킹에 누적**됩니다.
- 캐릭터보다 위쪽 화면을 탭하면 일시정지됩니다(똥피하기와 동일한 방식).

## 0003. 🧠 기억력 게임

- 카드를 뒤집어 같은 캐릭터 짝을 맞추는 게임입니다.
- 각 레벨 시작 전 **3초간 카드를 모두 앞면으로 보여주고 카운트다운**한 뒤, 뒤집혀서 "Start!"와 함께 시작됩니다.
- **레벨 1은 4장(2x2)**, 레벨이 오를 때마다 **4장씩** 늘어나 **레벨 12(48장)가 마지막**입니다. 카드 수에 맞춰 화면을 스크롤 없이 꽉 채우도록 카드 크기와 배치(nxm)가 자동으로 조정됩니다.
- 카드 그림은 01~08번(똥피하기 캐릭터)과 09~64번(귀여운 동물 이모지 56종) 중에서 매 레벨마다 무작위로 뽑습니다.
- 짝을 맞추면 카드가 초록 테두리 + 체크 표시로 그대로 뒤집힌 채 남고, **점수 +10**. 틀려도 감점은 없지만 시간은 계속 흐릅니다.
- **레벨당 20번**까지 틀릴 수 있고, 넘으면 게임 종료됩니다.
- 12레벨을 모두 클리어하면 **클리어**(클리어까지 걸린 시간으로 순위 결정), 중간에 게임이 끝나면 **점수**로 순위가 매겨집니다. (클리어 기록이 항상 미클리어 기록보다 순위가 높습니다)
- 오른쪽 위 ⏸ 버튼으로 일시정지할 수 있습니다.

## 0004. 🦟 벌레 소탕

- 시작할 때 **닌자 판다**와 **드래곤** 중 하나를 선택합니다(똥피하기 04·08번 캐릭터).
- 밤 골목의 가로등 불빛 아래로 벌레(모기·파리·나방)가 몰려듭니다. 캐릭터가 화면 아래쪽에서 **미사일을 자동으로 계속 발사**합니다.
- 하단 버튼 3개(**◀ / 🧴 / ▶**)로 조작합니다: ◀ ▶는 누르고 있는 동안 계속 움직이고, 가운데는 에프킬라 스프레이입니다.
- 벌레는 **10마리로 시작**해 **0.5초마다 한 마리씩** 늘어납니다. 미사일에 맞은 벌레는 사라지고 **점수 +10**.
- 화면의 벌레 수가 **50마리를 넘으면 게임 종료**입니다. 상단에 "벌레: N/50"으로 표시됩니다.
- 에프킬라 스프레이는 **2개**로 시작하고, 쓰면 그 순간 화면의 일반 벌레가 **모두** 떨어지며 사라집니다(최대 2개).
- **100마리를 잡으면 대왕 벌레(🦗 대왕 초록 메뚜기 / 🐝 대왕 노란 벌)가 랜덤으로 등장**합니다. 미사일 **3방**을 맞아야 죽고, 죽으면 스프레이가 천천히 떨어지는데 캐릭터가 직접 받아야 스프레이가 1개 늘어납니다(못 받으면 그냥 사라짐). 스프레이를 쓰면 대왕 벌레는 에너지가 **1칸만** 깎입니다.
- 캐릭터보다 위쪽 화면을 탭하면 일시정지됩니다(다른 게임과 동일한 방식).

## 실행 방법

### 1. 이 PC에서 바로 하기

`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행됩니다.

### 2. 휴대폰에서 하기 (같은 Wi-Fi)

가장 간단한 방법입니다. **휴대폰과 PC가 같은 Wi-Fi에 연결**되어 있어야 합니다.

1. `게임서버-시작.bat` 파일을 더블클릭합니다.
2. 검은 창에 표시되는 주소를 확인합니다. (예: `http://192.168.45.143:8000`)
3. 휴대폰 브라우저 주소창에 그 주소를 입력합니다.
4. 게임이 실행됩니다! 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
   - iPhone(Safari): 공유 버튼 → "홈 화면에 추가"
   - Android(Chrome): 메뉴(⋮) → "홈 화면에 추가"

> 게임을 하는 동안 검은 창은 켜 둔 채로 두세요. 창을 닫으면 서버가 꺼집니다.

**주소가 안 열린다면?**
- 휴대폰과 PC가 같은 Wi-Fi인지 확인하세요. (휴대폰 데이터가 켜져 있으면 꺼보세요)
- Windows 방화벽 팝업이 뜨면 **"액세스 허용"**을 눌러주세요.

### 3. 인터넷 주소로 어디서나 하기 (이미 배포됨)

**https://leternall.github.io/ddong-game/**

Wi-Fi가 달라도, 밖에서도, 링크를 받은 사람이면 누구나 열 수 있습니다.

게임을 수정한 뒤 다시 올리려면:

git add -A

푸시하고 1~2분 뒤 위 주소에 자동으로 반영됩니다.

## 게임 추가하기

1. `games/000N-게임이름/` 폴더를 새로 만들고 그 안에서 완결된 게임(index.html, style.css, game.js)을 만듭니다.
   - 허브로 돌아가는 링크는 `../../index.html` 입니다.
2. 루트 `hub.js`의 `GAMES` 배열에 한 항목을 추가합니다.
   - `desc`는 허브 카드에서 **한 줄로만** 보이도록 12~14자 정도로 짧게 씁니다(길면 CSS에서 잘려 보입니다). 자세한 설명은 게임 안쪽 화면에 쓰면 됩니다.
   - `thumb` 이미지는 캐시 문제로 안 바뀐 것처럼 보일 수 있으니, 대표 이미지를 다시 찍어 덮어쓸 때마다 `?v=N` 뒤 숫자를 하나씩 올려주세요.

```js
const GAMES = [
  // ...기존 게임들
  {
    id: "0005",
    title: "새 게임",
    desc: "한 줄 설명",
    path: "games/0005-새게임/index.html",
    thumb: "games/0005-새게임/assets/thumb.png?v=1", // 이미지가 없으면 emoji 사용
    ready: true,
  },
];
```

허브 화면에 자동으로 나타납니다.

3. 새 게임이 자체 랭킹(localStorage)을 쌓는다면, 루트 `rankings.js`의 `RANK_GAMES` 배열에도 한 항목을 추가해야 랭킹 화면에 나타납니다.
   - `key`는 그 게임 `game.js`의 `RANKING_KEY`와 정확히 같아야 합니다.
   - `format`은 점수만 저장하는 게임이면 `"score"`, 기억력 게임처럼 클리어 여부+시간까지 저장하는 게임이면 `"run"`입니다.

```js
const RANK_GAMES = [
  // ...기존 게임들
  { id: "0005", title: "새 게임", key: "새게임-rankings", format: "score" },
];
```

## 캐릭터 추가하기 (똥피하기)

캐릭터 번호(01~64)는 프로젝트 전체에서 공유하는 번호입니다. 01~08번은 실제 그림 캐릭터, 09~64번은 0003 기억력 게임의 동물 이모지 카드로 이미 다 쓰였으니, **새로 그림을 그려 넣는 캐릭터는 65번부터** 붙여주세요.

1. 캐릭터 그림을 **배경이 지워진 투명 PNG**로 만들어 `games/0001-ddong-pihagi/assets/` 폴더에 넣습니다.
   (배경 제거가 필요하면 **초록색 단색 배경**으로 그린 그림을 주는 것이 가장 깔끔합니다)
2. `games/0001-ddong-pihagi/game.js` 위쪽의 `CHARACTERS` 목록에 한 줄 추가합니다. `hitSrc`(게임오버 때 보이는 맞은 모습)는 없으면 생략해도 되고, 그러면 평소 모습 그림이 대신 쓰입니다. 선택 화면에 바로 나오게 하려면 `selectable`을 넣지 않으면 되고(기본값 true), 03~08번처럼 다른 게임 전용으로만 쓰려면 `selectable: false`를 추가합니다.

```js
const CHARACTERS = [
  { no: "01", id: "girl",   name: "소녀 캐릭터", src: "assets/character_girl.png", hitSrc: "assets/character_girl_hit.png" },
  // ...
  { no: "08", id: "dragon", name: "드래곤", src: "assets/character_dragon.png", selectable: false },
  { no: "65", id: "new",    name: "새 캐릭터", src: "assets/character_new.png" },  // 추가
];
```

`selectable`이 false가 아닌 캐릭터만 선택 화면에 번호와 함께 나타납니다.
